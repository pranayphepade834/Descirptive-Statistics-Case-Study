# Employee Data Analysis

## About the Project

This project performs basic Employee Data Analysis using Python.

The project uses Pandas, NumPy, Matplotlib, and Seaborn to analyze employee data and create different charts.

## Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## What This Project Does

- Loads the Employee dataset
- Displays the first few records
- Checks dataset shape and information
- Creates different visualizations
- Filters employee records based on conditions

## Visualizations

The project creates:

- Age vs Salary Scatter Plot
- Healthy Eating vs Active Lifestyle Scatter Plot
- Healthy Eating vs Salary Scatter Plot
- Groups Count Plot
- Salary Histogram

## Data Filtering

The project finds:

- Employees with healthy eating score greater than 8
- Employees with salary less than 1000
- Employees with healthy eating score greater than 8 and salary less than 1000
